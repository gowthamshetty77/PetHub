# PetHub
# Developed by GOWTHAM

PetHub is a comprehensive platform designed for pet owners to easily book pet products, such as food and accessories, and schedule veterinary appointments. 
The application aims to enhance the pet care experience by providing a user-friendly interface for both pet owners and administrators.

# Features:
User Registration: Users can register using their email or mobile number, with OTP verification for security.
Product Booking: Users can browse and book various pet products.
Veterinary Appointments: Schedule appointments with veterinarians based on availability.
Admin Management: Administrators can manage product listings, view user bookings, and access reviews to improve service quality.
User Reviews: Users can leave reviews on products and services, contributing to community feedback.

# Technologies Used:
The PetHub platform is built using a variety of technologies:
Backend: J2EE, Servlets, JDBC, Java
Frontend: jQuery, JavaScript, HTML, CSS
Database: MySQL
